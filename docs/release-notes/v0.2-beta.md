# Fractal v0.2-beta

The second public beta of **Fractal**, a Wii U emulator for Android handhelds and phones, forked from Cemu and tuned
for Adreno and Mali GPUs. This release covers everything since the updated v0.1-beta build of 15 November 2026: 118
commits, 814 files changed, about 30 thousand lines added and 104 thousand removed (most of them desktop code).

> **This is a beta.** Results still change from one device or GPU driver to another. Back up your saves and report what
> you find.

Devices named below: **RP5** = Retroid Pocket 5 (Snapdragon 865, Adreno 650), **POCO** = POCO X6 Pro (Dimensity 8300
Ultra, Mali-G615), **Mi A3** = Xiaomi Mi A3 (Snapdragon 665, Adreno 610), **Odin 3** = AYN Odin 3 (Snapdragon 8 Elite,
Adreno 830). The **system driver** is the phone's own Vulkan driver (Qualcomm or Arm); **Turnip** (Adreno) and
**PanVK** (Mali) are the Mesa custom drivers.

## Highlights

- **Performance HUD** in the look of your theme: FPS, frame time, CPU and GPU load, temperatures, RAM, battery and power
  draw. Pick what it shows, its size, opacity and layout, and drag it anywhere.
- **Graphic packs and cheats in the in-game menu**, applied to the running game (resolution packs still ask for a
  restart). The game's settings also open from the in-game menu, with a **Restart game** button.
- **Community shader caches:** download a game's shared cache from its settings and play with fewer stutters the first
  time; share yours anonymously, no account needed.
- **Choose where Fractal keeps its data** (internal storage or SD card), and install mods from a .zip or a folder.
- **Samsung Xclipse (Exynos) GPUs** can now use custom RADV drivers (not tested on an Exynos device yet), and faux123's
  PanVK joins the Mali drivers.
- **Faster on ARM:** hardware AES and CRC32 and new NEON code for disc reads, game loading, index buffers and texture
  decoding on Mali; the recompiler handles many more instructions; the native library is built with profile guided
  optimization (Watch Dogs on the Odin 3: 51.4 → 56.1 fps); the emulated CPU and the GPU thread stay on the big cores
  (The Amazing Spider-Man 2 on the RP5: 34.9 → 40.3 fps).
- **Less texture memory on the Qualcomm and Mali drivers:** compressed textures stay compressed (as ASTC) instead of
  growing 4-8x; Super Mario 3D World uses half the texture memory on a Mi A3.
- **Less RAM:** guest memory clears skip pages that are already zero, so Android doesn't back them with real RAM
  (Mario Kart 8 on a Mi A3: 1410 → 997 MB at 100 s).
- **Games with streamout run much faster on Mali:** Call of Duty: Black Ops II on a POCO X6 Pro goes from 17 to 35 fps
  on the Mali driver (3 → 16 on PanVK).
- **Shader caches no longer break:** a bug inherited from Cemu could damage a cache file as it grew, making the game
  use 2 GB of RAM at boot (closed by Android on 4 GB phones) and recompile almost every shader. Damaged caches repair
  themselves.
- **Android only:** all the desktop code is gone (about 103 thousand lines), and the native library is 22.7 → 18.4 MB.
- **Mali fixes:** missing characters, black patches on normal maps and a render target crash fixed on the Mali driver;
  PanVK no longer closes every game on its first frame.
- **About 30 games fixed or improved**, from Super Smash Bros. and Splinter Cell: Blacklist to Monster Hunter 3
  Ultimate and Batman: Arkham City, and new default profiles that pick the driver that doesn't crash.
- Controller type per game, with a hint when a game ignores your setup; a lower resolution offered once when a game runs
  well below full speed; your own menu music and sounds; the debug report offered after a crash.

## New features

### Performance HUD

- FPS, CPU and GPU load, CPU and battery temperatures, RAM, power draw, battery level and charging, and the GPU model,
  drawn over the game. Ported from StevenMXZ's Winlator-Ludashi HUD (GPL-3.0) (`bc5372e2`).
- Each theme (Solid, Liquid Glass, Blur, Material You, Synthwave) paints it its own way, with every color checked for
  contrast.
- Items, size, background opacity, row or column and position (presets, reset, or dragged with a finger) in the overlay
  settings and in the in-game menu. It sits over the on-screen controls but only takes touches on itself.
- Cheap by design: once a second it reads only the statistics on screen, and stops when the HUD is off.
- **GPU usage on phones that hide it** (the Mi A3 showed N/A): measured from the emulator's own command buffer
  timestamps while the HUD shows it. Mi A3, Kirby and the Rainbow Curse: GPU 98 %, fps unchanged (28.9 vs 29.1)
  (`b558e01a`).
- The classic overlay's **frame time, frame generation, draw calls and Fractal's own CPU and RAM use** are HUD items too
  (off by default), gathered even with the classic overlay off (`378222ec`).

### In-game menu

- **Graphic packs and cheats:** a new entry lists only the running game's packs, cheats and mods. Turning a pack on or
  off or changing a preset applies it to the running game, like Cemu's graphic packs window on PC. Packs with texture
  rules (most resolution packs) still need a restart, and a message says which of the two happened (issue #5)
  (`c6522627`).
- **Game settings:** the running game's profile opens with the game paused; changes are saved at once and **Restart
  game** relaunches the title so they take effect (`98364ff2`).

### Community shader caches

- A **Community shaders** section in each game's settings downloads the shared cache from
  [Fractal_Shaders](https://github.com/dfdx047/Fractal_Shaders). Its size and version are checked, your local cache is
  backed up, and the new entries are merged into it (nothing is replaced; with no local cache the file is copied).
  Desktop Cemu caches of the same game use the same format (`63968db1`).
- **Sharing is anonymous:** no GitHub account; each install sends only a random id. Every submission is reviewed before
  it is merged into the shared cache (`c75e10c7`).
- Tested with Deus Ex: shared from the POCO, downloaded on the RP5, which then built all 92 large shaders on the
  loading screen instead of during play.

### Data folder and mods

- **Settings › System › Emulator data folder:** pick a folder in internal storage or on an SD card instead of
  `Android/data`, which newer Android versions hide from file managers and which is deleted with the app. Fractal asks
  for "All files access", moves the data (with progress when it has to copy) and restarts. If the folder becomes
  unusable (card removed, permission revoked) the default folder is used and the screen says so. Going back can move
  the data back or leave it. (`5f607b21`, `af271be2`).
- **Mod install** from a .zip or a folder, in a new Mods card of the graphic packs screen, with a short guide. Packs
  with `rules.txt` go to `graphicPacks/mods`; console mods (SDCafiine `content`/`aoc`/`code` folders) ask for the game
  and get a `rules.txt`, grouped with that game's packs (`5f607b21`).

### Controls

- **Player 1 controller per game** (GamePad / Pro / Classic / Wiimote) in the game settings. It only changes this
  game: the connected gamepad is mapped to that type when the game starts (`5e6c4e42`).
- About 20 s into a game, a **one-time hint** when the game may ignore your setup (a Pro Controller in a game that reads
  the GamePad, or the GamePad in a game that never reads it), with a button that fixes it for this game and applies it
  to the running game.
- **Nintendo button layout** option (face buttons by position); controller slots named "Player N · type".
- **Gyro:** with motion on, the in-game menu has **Calibrate gyro**: hold the device the way you play and tap, and games
  that aim by tilting the GamePad (Splatoon) aim straight ahead in that position. **Reset gyro calibration** goes back
  to the device's own axes; calibration also has a hotkey. The aim no longer slides to the floor or the sky for about
  10 s after motion is turned on, and the axes follow the screen when it turns 180 degrees (`71f9f21a`).

### Resolution hint

- After a minute of play at a median under 22 fps, a game whose graphic packs have a resolution option you haven't set
  is offered 640x360 once (or the smallest option from 360p), with a restart. On an Adreno 610: Kirby and the Rainbow
  Curse 12 → 27 fps, New Super Mario Bros. U 20 → 34, Captain Toad 16 → 30. It works with the overlay off too
  (`08c67298`).

### Menu music and sounds

- Library background music per theme (an intro played once, then a gapless loop) and menu sound effects (navigate,
  cover, swap, confirm), each with on/off and volume (default 25 %), in Appearance and the welcome screen (`98364ff2`,
  `f1d24be9`).
- **Your own sounds** (Appearance › Sounds): a music file to play in the library instead of the theme's track, and a
  file for each menu effect (up to 5 s each). Choose, Listen and Remove buttons; a switch goes back to the Fractal
  sounds without losing your choice (`c8e0da47`).

### Debug report after a crash

- When the game or the library crashed or stopped responding, the next launch says so and offers to share
  `debug_report.zip`, with what it contains and where to post it (issue #2). Closing the app from recents or a restart
  after a settings change doesn't count (`40d57923`).

### GPU drivers

- **Samsung Xclipse** (Exynos 2200/2400/2500, 1480/1580) is detected and gets RADV custom drivers in the drivers screen:
  JimVulkan/radv-xclipse, paulowesll/mesa, JesusChapman/radv-xclipse-mainline, aaditya-v-more/xclipse-driver (Xclipse
  940) and nowhere02/xclipse550-radv-pgo (Xclipse 550, experimental). Builds for Winlator and proot in the same releases
  are filtered out. Not tested on an Xclipse device yet; if a driver fails, the driver guard goes back to the system
  driver (`8da0d804`).
- **faux123's universal PanVK** package for Mali-G57/G77/G610/G710 class GPUs in the driver list (`45be70a4`).

### Textures on drivers without BCn (Qualcomm and Mali system drivers)

- **BC1-BC3 as ASTC 4x4 (on by default):** instead of decoding them to RGBA8 (4x larger for BC2/BC3, 8x for BC1), Fractal
  transcodes them on the CPU to ASTC 4x4 blocks of the same size as BC, a direct block-to-block conversion. Quality
  against the original: BC1 53-58 dB, BC3 48.5 dB. Used where both ASTC 4x4 formats can be sampled with linear filtering;
  1D and 3D textures stay RGBA8. Regression on the RP5, POCO, Mi A3 and Odin 3 with every driver, no crash.
  `bc_transcode=0` turns it off (`5a3ce661`, `07a486b3`, `51de9091`, `e7ca709f`).
- **BCn decoding through a palette per block, with NEON:** a 4x4 block has at most 8 values, so the palette is
  converted to bytes once and the texels are copied with NEON table lookups, bit exact with the old code (`c4e6b0aa`).
- **No more zero-filling of the upload buffer:** the whole decoded image was cleared before every texture slice was
  decoded (5.6 MB for a 1024x1024 RGBA8 mip chain); the buffer now only grows (`cdb338ed`).
- In the build but **off by default:** BC to ETC2/EAC transcoding (`bc_transcode_etc` 1-3; with ASTC on, BC1-BC3 go to
  ASTC and ETC2/EAC keeps BC4/BC5; BC1-BC3 to ETC2 cost 25 % in Batman on Mali, and EAC gave no fps or memory gain on
  the Mi A3), and a worker pool that decodes large textures in row ranges (`tex_decode_threads`; 2.5-2.6x faster
  decodes on a desktop test, no fps change on any phone) (`dc9c0067`, `9c63694e`, `81fcd9a7`).

### Streamout

- **Streamout copies wait for the end of the render pass:** games that use streamout (transform feedback) no longer end
  the render pass on every draw that writes it. See the table for Black Ops II. Regression on the RP5, POCO, Mi A3 and
  Odin 3 with no crash. `so_defer_copies=0` goes back to the old behaviour (`451ecf49`).

### CPU and system

- **Big cores:** the emulated CPU cores and the GPU command thread stay off the little cluster (CPUs below 75 % of the
  largest capacity); Android put them on the Cortex-A55 of the Snapdragon 865 often enough to cost a lot. No change on
  the POCO and the Mi A3; nothing is pinned on CPUs without a little cluster (Snapdragon 8 Elite). `big_cores=0` turns
  it off (`683c6772`).
- **Save battery** (general settings, off by default): the emulated main core no longer spins at 100 % of a host core
  while it waits for work. When it was idle at least 80 % of the last 250 ms it sleeps until the next alarm; a game that
  needs the core keeps spinning. Splatoon on the Odin 3 (60 fps): 6.7 → 4.8 W, CPU 144 → 120 %; New Super Mario Bros. U
  on the RP5: CPU 147 → 131 %. The cost is a slightly less even frame pace, 2-3 fps of 1 % low (Splatoon 57 → 54, NSMBU
  49 → 47). Super Mario 3D World on the RP5, the POCO and the Mi A3 unchanged (`2b5b0dca`, `fb53ac0b`).
- **Profile guided optimization (PGO):** the native library is built with a profile collected on the Odin 3, the POCO
  and the Mi A3 (19 games). Watch Dogs on the Odin 3: 51.4 → 56.1 fps (1 % low 41 → 45); Bayonetta 2 and Assassin's
  Creed III on the POCO slightly up; RP5 and Mi A3 unchanged (`0893c8b5`).
- **Android performance hints (ADPF), off by default:** a hint session that reports each frame's work to the CPU
  governor. It saved 7 % power in Watch Dogs on the Odin 3 but cost fps on the POCO (Bayonetta 2 33.2 → 26.3) and 1 %
  lows on the Odin 3. `adpf=1` turns it on (`0893c8b5`).
- **ARMv8 extensions**, detected at runtime so the build still runs on every arm64-v8a phone (AES, PMULL, CRC32, LSE
  atomics, FP16, dot product): AES-128 for encrypted disc reads (WUD/WUX, NUS content), CRC32 for the checks of every
  RPX/RPL section at load, and a NEON index buffer maximum that skips the primitive restart index (`b1078675`,
  `852801bb`, `64efc3e5`, `bd6af3dc`).

### Recompiler (PowerPC → ARM64)

- `addo`/`subfo`/`addco`/`subfco`, `mfxer`/`mtxer`, `fcmpo`, `bdnzf`-style branches, conditional branches outside the
  translated code, `subfme`, `divwo`/`divwuo` and `bcl 20` no longer send functions to the interpreter (`66f59e89`,
  `85b29bd9`).
- A huge contiguous function is translated in windows instead of whole for every new entry: in Teslagrad a 955 KB
  switch was translated 22 times (92 MB of host code). Teslagrad on the Mi A3: functions in the interpreter
  770 → 157 → 0; Disney Infinity 2.0: 145 → 0. Regression: 17 games on the RP5, POCO and Mi A3 with the same frame
  rates and pictures (`66f59e89`, `85b29bd9`).
- Fused multiply-add (`fmadd`/`fmsub`/`fnmsub` and single forms) rounds once, like the Wii U CPU and the interpreter;
  before, `a*c - round(a*c)` was zero only in recompiled code. Same speed and picture in Ninja Gaiden 3, Spider-Man 2
  and Splinter Cell: Blacklist (`fec3837f`).
- `stwcx.` on an unaligned address no longer crashes (it became an ARM64 atomic that needs 4 byte alignment)
  (`70eb6796`).

### Memory

- **GPU buffer cache of 256 MB** on phones with 6 GB of RAM or more (Cemu's 164 MB below that); see Cars 3.
  `buffer_cache_mb` overrides it (`f3f03341`).
- **Lighter guest memory clears (`lazy_zero`, on by default):** clears of 16 KB or more skip 4 KB pages that are
  already zero, so Android doesn't have to back them with real RAM. Mario Kart 8 on the Mi A3: process RAM at 100 s
  1410 → 997 MB; Watch Dogs skips 512 MB of clears; no fps change. `lazy_zero=0` turns it off (`e4ae9d51`).

All the switches above go in `perf/tuning.txt` in Fractal's data folder; without the file the defaults apply.

### Every game

- **Shader and pipeline caches:** when a cache file grew, the relocated file table's own entry was written at the old
  table offset, into the new table, leaving an entry that claimed about 4 GB. Reading it took 2 GB of RAM at boot and
  made almost every later pipeline read as corrupted (1247 of 1252 recompiled). The entry is now written with the
  table, damaged entries are dropped when the cache opens, and caches that were already damaged heal themselves. The
  same bug is in Cemu upstream (`9b3dde81`).
- Settings changed in the game's menu were overwritten by the library's older copy (`e91a7121`).
- The app no longer closes at start on custom ROMs that deny `Android/data`: it falls back to its private folder
  (issue #1) (`42a2fbd7`, `5f607b21`).

## Graphics and drivers

### Mali (Arm system driver)

- **Streamout through `VK_EXT_transform_feedback`** where the driver lacks vertex pipeline stores (the Mali driver):
  Yoshi and the enemies are back in Yoshi's Woolly World. `so_xfb` (-1 automatic, 1 always, 0 never) (`95904874`).
- **BC4/BC5 SNORM textures** (normal maps, in any game) decoded correctly on the CPU: negative values became 0 and values
  above 0.5 turned negative (`95904874`).
- **A2_B10_G10_R10 render targets** get a Vulkan format (Resident Evil Revelations crashed; Adreno drivers tolerated it)
  (`71f3a05a`).

### Adreno (Qualcomm system driver)

- **Shaders that read and write registers by index** keep separate variables instead of an array, which crashed the
  Qualcomm compiler (Pikmin 3). `relread_select=0` keeps the array form (`ab851c1a`).
- **Rect emulation geometry shader:** it now declares the same `gl_PerVertex` as the vertex shaders (Twilight Princess
  HD minimap) and writes every pixel shader input (Cars 3, Ninja Gaiden 3, Disney Infinity 3.0) (`a95f1b41`,
  `eca58396`).

### Adreno and Mali system drivers

- **No logic op on drivers without the `logicOp` feature:** raster ops other than COPY turned it on although the driver
  lacks it (invalid in Vulkan, result up to the driver); they now draw as COPY there. Turnip and PanVK are unchanged
  (`a0b305c5`).

### PanVK

- Every game crashed on its first frame with faux123's PanVK: it reports `VK_KHR_present_wait`, which Mesa's Android
  window system doesn't implement. It is off for PanVK now (`45be70a4`).
- Faster with the self-dependency change below (Need for Speed: Most Wanted U, Resident Evil Revelations, FIFA 13,
  Bayonetta 2 26.6 → 28.1 fps) and with deferred streamout copies (`4edbc727`, `451ecf49`).

### Every driver

- **Draws that sample their own color attachment** read a copy taken before the draw, also where
  `VK_EXT_attachment_feedback_loop_layout` exists (Paper Mario's dots) (`70eb6796`); pixel shaders that do it more than
  8 times in a frame go back to the feedback loop, so Breath of the Wild keeps its speed. `selfdep_copy_max_per_frame`
  (default 8) (`4edbc727`). On the Mali and Qualcomm system drivers, which have no feedback loop, those shaders split the
  render pass instead of copying: POCO X6 Pro (Mali) Need for Speed: Most Wanted U 17.2 → 28.8 fps, Resident Evil
  Revelations 24.9 → 30.0 fps, Breath of the Wild 5.9 → 15.6 fps (opening) (`b96b5dca`).
- **Occlusion queries:** results reach the game while the GPU is idle (`idle_query_poll=0` turns it off), queries that
  end with no host query running finish, a query ended twice or begun again early is handled (`1557a268`, `e5dc06a1`).
- A swap with nothing copied to the screen keeps the last picture (`de5d2869`).
- Copies into 1D surfaces use 2D copy targets, like cubemaps (`dd40e27e`).
- When the buffer cache is still full, streamout ranges unused for 2 frames are dropped as a last resort, and the
  allocation is retried only after a failure (`146fdb6e`, `eca58396`).

## Emulation core

- `OSMutex` priority inheritance, as Cafe OS does (`mutex_inherit=0` turns it off) (`5568a685`);
  `OSGetMapVirtAddrRange` and `OSGetDataPhysAddrRange` (`ad5d1dc1`); file truncation on Android, a stub upstream too
  (`8daaafec`); `getsockname` errors (`6b27c9ae`); title relaunch and exit on Android (`e2030e99`).
- A title starts without an update known to keep it from loading (ZombiU v32) (`b6cf7c8b`).
- Title fixes are a table of exact game code patterns per title ID (Ninja Gaiden 3, Monster Hunter 3 Ultimate, New
  Super Mario Bros. U, Hot Wheels) (`dd4aa043`, `ff719783`, `dfde2b64`).
- Fetch shaders whose clause has 5-8 or 13-16 fetches are detected; folder errors at start are logged instead of
  closing the app (`42a2fbd7`).

## Changes

- **Frame generation asks for the display's highest refresh rate** while it is on. Phones that keep apps at 60 Hz
  (Moto Edge 30 Ultra, issue #9) halved the game's own frame rate, because the generated frames wait for the display
  (`0f0cc53b`).
- **Smaller app:** third-party symbols are no longer exported from the native library (22.73 → 18.45 MB, 7.85 MB
  gzipped); unused resources are dropped at build time (resources 1.49 → 0.83 MB); only arm64 libraries are packaged;
  graphic packs download with Android's own HTTP client instead of Ktor (classes.dex 6.10 → 5.07 MB) (`bc69967a`, `10bd5abd`,
  `5e0236a6`).
- Dialog buttons look like the app's buttons and share the dialog width, cancel on the left and confirm on the right, or
  stack when a label doesn't fit (`af271be2`).
- The classic overlay is renamed and points to the performance HUD (`378222ec`).
- Crash reports name the texture when the texture cache stops on an error (`dd40e27e`).

- The wxWidgets desktop interface (main window, settings, debugger, title manager) (`9aa94b36`).
- The OpenGL and Metal renderers; Vulkan was the only one the Android build ever used (`ee6e63b1`).
- The x86-64 recompiler and x86 CPU detection (`d07f65ea`).
- Windows, macOS and desktop Linux code, installers, icons and bundles, and the shader cache merger tool (`54b44032`).
- SDL, XInput, DirectInput, native Wii remotes and the GameCube adapter, DirectSound and XAudio, and Discord Rich

- Desktop build options, packaging and CI (`4b0f2868`).
- Native and Kotlin code that nothing called, including the old unit tests (`56d83cd7`, `054ddf0f`).
- Settings and game profiles keep the same values, so existing settings load as before.

## Known issues

- **Splinter Cell: Blacklist:** in missions only the sky and the ground are drawn (the Cemu compatibility wiki lists the
  same problem).
- **Assassin's Creed III on Mali:** nearby terrain can be flat dark blue (in multi-core the game doesn't send the
  terrain draw; single-core draws it).
- **The Binding of Isaac: Rebirth (USA):** black picture (sound plays, no crash).
- **FIFA 13:** can crash in its audio thread on the RP5 (about 3 runs in 10), with every driver. The pitch and the
  stadium are black on every GPU; official Cemu shows a black screen too (cemu-project/Cemu#1907).
- **Mario Kart 8 on the Mi A3 (Adreno 610):** the game closes when a race loads (a GPU fault inside the Qualcomm driver;
  Turnip T19 restarts the phone). It is not memory any more, and the RP5 runs it normally.
- **Need for Speed: Most Wanted U:** a rare crash on the POCO (not seen in the last 7 runs); white foliage without the
  Bloom Fix pack (on by default).
- **Assassin's Creed IV:** the jungle can still turn black with only the HUD left (rare).
- **Watch Dogs:** the first room can come out overexposed (bright instead of dark) in about half of the runs on
  Android; on the RP5 Turnip can hang the GPU in long sessions (use the system driver there); on the Odin 3 the system
  driver sometimes closes it at boot (use Turnip there); stuck compiling shaders on the RG Cube.
- **Ninja Gaiden 3 on Turnip:** dark floating heads and a blown-out sky in some scenes.
- **Xenoblade Chronicles X on the Qualcomm system driver:** white silhouettes; use Turnip.
- **Pokkén Tournament on the Odin 3 (Adreno 830) with the Qualcomm system driver:** the arena turns into colored noise
  in battles (menus and dialogue are fine). Not new (v0.1 does it too); use Turnip, which draws it correctly at 60 fps.
- **Pipeline caches from another phone:** Watch Dogs on the Odin 3 closed at boot with a cache made on another device
  (the Turnip Gen8 and Qualcomm compilers crash on some of its pipelines); with its own cache it plays.
- **Phones with only two big cores:** the emulated CPU and the GPU thread share them. If such a phone got slower,
  `big_cores=0` in `perf/tuning.txt` restores the old behaviour.
- **Textures on the Qualcomm and Mali system drivers** are now ASTC; if one looks wrong, compare with `bc_transcode=0`
  and report it.
- Custom Mali drivers (PanVK) are still experimental. Android has no immediate present mode: VSync off behaves like
  double buffering.

report** at any time. Attach `debug_report.zip` to a [new issue](https://github.com/dfdx047/Fractal/issues/new/choose)
with your device, GPU driver and the game's Title ID. Please do not report Fractal bugs to the Cemu team.

# Fractal v0.2-beta

A segunda beta pública do **Fractal**, um emulador de Wii U para portáteis e celulares Android, derivado do Cemu e
ajustado para GPUs Adreno e Mali. Esta versão reúne tudo o que entrou desde a build atualizada da v0.1-beta, de 15 de
novembro de 2026: 118 commits, 814 arquivos alterados, cerca de 30 mil linhas a mais e 104 mil a menos (quase tudo
código de desktop).

> **Isto é uma beta.** O resultado ainda muda de um aparelho ou driver de GPU para outro. Faça backup dos seus saves e
> conte o que encontrar.

Aparelhos citados: **RP5** = Retroid Pocket 5 (Snapdragon 865, Adreno 650), **POCO** = POCO X6 Pro (Dimensity 8300
Ultra, Mali-G615), **Mi A3** = Xiaomi Mi A3 (Snapdragon 665, Adreno 610), **Odin 3** = AYN Odin 3 (Snapdragon 8 Elite,
Adreno 830). O **driver do sistema** é o driver Vulkan do próprio celular (Qualcomm ou Arm); **Turnip** (Adreno) e

- **HUD de desempenho** com o visual do seu tema: FPS, tempo de quadro, uso de CPU e GPU, temperaturas, RAM, bateria e
  consumo. Escolha o que ele mostra, o tamanho, a opacidade e a disposição, e arraste para onde quiser.
- **Graphic packs e cheats no menu do jogo**, aplicados com o jogo rodando (packs de resolução ainda pedem para
  reiniciar). As configurações do jogo também abrem pelo menu do jogo, com um botão **Reiniciar o jogo**.
- **Caches de shaders da comunidade:** baixe o cache compartilhado de um jogo nas configurações dele e jogue com menos
  engasgos já na primeira vez; compartilhe o seu de forma anônima, sem conta.
- **Escolha onde o Fractal guarda os dados** (armazenamento interno ou cartão SD) e instale mods de um .zip ou de uma
  pasta.
- **GPUs Samsung Xclipse (Exynos)** agora podem usar drivers RADV customizados (ainda não testados num aparelho
  Exynos), e o PanVK do faux123 entra na lista de drivers para Mali.
- **Mais rápido no ARM:** AES e CRC32 por hardware e código NEON novo para leitura de discos, carregamento dos jogos,
  index buffers e decodificação de texturas na Mali; o recompilador trata muito mais instruções; a biblioteca nativa é

- **Caches de shaders não estragam mais:** um bug herdado do Cemu podia estragar o arquivo de cache quando ele crescia,
  e o jogo passava a usar 2 GB de RAM ao abrir (fechado pelo Android em celulares de 4 GB) e a recompilar quase todos os
  shaders. Caches estragados se consertam sozinhos.
- **Só Android:** todo o código de desktop saiu (cerca de 103 mil linhas) e a biblioteca nativa caiu de 22,7 para

- **Correções para Mali:** personagens faltando, manchas pretas nos normal maps e um crash de render target corrigidos

- **Cerca de 30 jogos corrigidos ou melhorados**, do Super Smash Bros. e do Splinter Cell: Blacklist ao Monster Hunter
  3 Ultimate e ao Batman: Arkham City, e perfis padrão novos que escolhem o driver que não trava.
- Tipo de controle por jogo, com aviso quando o jogo ignora a sua configuração; uma resolução menor oferecida uma vez
  quando o jogo roda bem abaixo da velocidade cheia; música e sons do menu escolhidos por você; o relatório de
  depuração oferecido depois de um crash.

#### Texturas nos drivers sem BCn (drivers do sistema da Qualcomm e da Mali)

- **BC1-BC3 como ASTC 4x4 (ligado por padrão):** em vez de decodificar para RGBA8 (4 vezes maior no BC2/BC3, 8 vezes no
  BC1), o Fractal converte na CPU para blocos ASTC 4x4 do mesmo tamanho do BC, bloco a bloco. Qualidade em relação ao
  original: BC1 53-58 dB, BC3 48,5 dB. Vale onde os dois formatos ASTC 4x4 podem ser amostrados com filtro linear;
  texturas 1D e 3D continuam em RGBA8. Regressão no RP5, POCO, Mi A3 e Odin 3 com todos os drivers, sem crash.
  `bc_transcode=0` desliga (`5a3ce661`, `07a486b3`, `51de9091`, `e7ca709f`).
- **Decodificação BCn por paleta de cada bloco, com NEON:** um bloco 4x4 tem no máximo 8 valores, então a paleta é
  convertida para bytes uma vez só e os texels são copiados com consultas de tabela NEON, bit a bit igual ao código
  antigo (`c4e6b0aa`).
- **Fim do preenchimento com zeros do buffer de upload:** a imagem decodificada inteira era zerada antes de cada fatia
  de textura (5,6 MB numa cadeia de mips 1024x1024 RGBA8); agora o buffer só cresce (`cdb338ed`).
- Na build, mas **desligados por padrão:** conversão de BC para ETC2/EAC (`bc_transcode_etc` 1-3; com o ASTC ligado,
  BC1-BC3 vão para ASTC e o ETC2/EAC fica com BC4/BC5; BC1-BC3 em ETC2 custaram 25 % no Batman na Mali, e o EAC não deu
  ganho de fps nem de memória no Mi A3), e um pool de workers que decodifica texturas grandes em faixas de linhas
  (`tex_decode_threads`; decodificação 2,5-2,6 vezes mais rápida num teste no PC, fps igual em todos os celulares)
  (`dc9c0067`, `9c63694e`, `81fcd9a7`).

#### Streamout

- **As cópias de streamout esperam o fim do render pass:** jogos que usam streamout (transform feedback) não encerram
  mais o render pass a cada draw que escreve nele. Veja o Black Ops II na tabela. Regressão no RP5, POCO, Mi A3 e Odin 3
  sem crash. `so_defer_copies=0` volta ao comportamento antigo (`451ecf49`).

#### CPU e sistema

- **Núcleos grandes:** os núcleos emulados e a thread de comandos da GPU ficam fora do cluster pequeno (CPUs abaixo de
  75 % da maior capacidade); o Android as colocava nos Cortex-A55 do Snapdragon 865 com frequência suficiente para
  custar caro. Sem mudança no POCO e no Mi A3; nada é fixado em CPUs sem cluster pequeno (Snapdragon 8 Elite).
  `big_cores=0` desliga (`683c6772`).
- **Economizar bateria** (configurações gerais, desligado por padrão): o núcleo principal emulado não gira mais a 100 %
  de um núcleo do aparelho enquanto espera trabalho. Quando ficou ocioso em pelo menos 80 % dos últimos 250 ms, ele
  dorme até o próximo alarme; um jogo que precisa do núcleo continua girando. Splatoon no Odin 3 (60 fps): 6,7 → 4,8 W,
  CPU 144 → 120 %; New Super Mario Bros. U no RP5: CPU 147 → 131 %. O custo é um ritmo de quadros um pouco menos
  regular, 2-3 fps de 1 % low (Splatoon 57 → 54, NSMBU 49 → 47). Super Mario 3D World no RP5, no POCO e no Mi A3 igual
  (`2b5b0dca`, `fb53ac0b`).
- **Otimização guiada por perfil (PGO):** a biblioteca nativa é compilada com um perfil coletado no Odin 3, no POCO e no
  Mi A3 (19 jogos). Watch Dogs no Odin 3: 51,4 → 56,1 fps (1 % low 41 → 45); Bayonetta 2 e Assassin's Creed III no
  POCO um pouco acima; RP5 e Mi A3 iguais (`0893c8b5`).
- **Dicas de desempenho do Android (ADPF), desligadas por padrão:** uma sessão de dicas que informa o trabalho de cada
  quadro ao governador da CPU. Economizou 7 % de energia no Watch Dogs no Odin 3, mas custou fps no POCO (Bayonetta 2
  33,2 → 26,3) e 1 % lows no Odin 3. `adpf=1` liga (`0893c8b5`).
- **Extensões ARMv8**, detectadas em tempo de execução para a build continuar rodando em todo celular arm64-v8a (AES,
  PMULL, CRC32, atômicos LSE, FP16, produto escalar): AES-128 nas leituras de disco criptografadas (WUD/WUX, conteúdo
  NUS), CRC32 nas verificações de cada seção RPX/RPL ao carregar, e máximo de index buffer com NEON que pula o índice
  de primitive restart (`b1078675`, `852801bb`, `64efc3e5`, `bd6af3dc`).

#### Recompilador (PowerPC → ARM64)

- `addo`/`subfo`/`addco`/`subfco`, `mfxer`/`mtxer`, `fcmpo`, desvios no estilo `bdnzf`, desvios condicionais para fora
  do código traduzido, `subfme`, `divwo`/`divwuo` e `bcl 20` não mandam mais funções para o interpretador (`66f59e89`,
  `85b29bd9`).
- Uma função contígua enorme é traduzida em janelas, em vez de inteira a cada entrada nova: no Teslagrad um switch de
  955 KB era traduzido 22 vezes (92 MB de código host). Teslagrad no Mi A3: funções no interpretador 770 → 157 → 0;
  Disney Infinity 2.0: 145 → 0. Regressão: 17 jogos no RP5, POCO e Mi A3 com o mesmo fps e a mesma imagem (`66f59e89`,
  `85b29bd9`).
- Multiplicação-soma fundida (`fmadd`/`fmsub`/`fnmsub` e as formas single) arredonda uma vez só, como a CPU do Wii U e o
  interpretador; antes, `a*c - round(a*c)` dava zero só no código recompilado. Mesma velocidade e imagem no Ninja
  Gaiden 3, Spider-Man 2 e Splinter Cell: Blacklist (`fec3837f`).
- `stwcx.` num endereço desalinhado não fecha mais o jogo (virava um atômico ARM64 que exige alinhamento de 4 bytes)
  (`70eb6796`).

#### Memória

- **Cache de buffers da GPU de 256 MB** em celulares com 6 GB de RAM ou mais (abaixo disso, os 164 MB do Cemu); veja o
  Cars 3. `buffer_cache_mb` muda o valor (`f3f03341`).
- **Limpezas de memória do jogo mais leves (`lazy_zero`, ligado por padrão):** limpezas de 16 KB ou mais pulam
  páginas de 4 KB que já estão zeradas, e o Android não precisa reservar RAM de verdade para elas. Mario Kart 8 no Mi A3:
  RAM do processo aos 100 s 1410 → 997 MB; o Watch Dogs pula 512 MB de limpezas; fps igual. `lazy_zero=0` desliga
  (`e4ae9d51`).

Todas as chaves acima vão em `perf/tuning.txt`, na pasta de dados do Fractal; sem o arquivo, valem os padrões.

### Gráficos e drivers

#### Mali (driver do sistema da Arm)

- **Streamout por `VK_EXT_transform_feedback`** onde o driver não tem escrita em buffers no pipeline de vértices (o
  driver da Mali): o Yoshi e os inimigos voltam no Yoshi's Woolly World. `so_xfb` (-1 automático, 1 sempre, 0 nunca)
  (`95904874`).
- **Texturas BC4/BC5 SNORM** (normal maps, em qualquer jogo) decodificadas certo na CPU: valores negativos viravam 0 e
  valores acima de 0,5 ficavam negativos (`95904874`).
- **Render targets A2_B10_G10_R10** ganham um formato Vulkan (o Resident Evil Revelations fechava; os drivers da Adreno
  toleravam) (`71f3a05a`).

#### Adreno (driver do sistema da Qualcomm)

- **Shaders que leem e escrevem registradores por índice** usam variáveis separadas em vez de um array, que derrubava o
  compilador da Qualcomm (Pikmin 3). `relread_select=0` mantém a forma com array (`ab851c1a`).
- **Geometry shader da emulação de rects:** agora declara o mesmo `gl_PerVertex` dos vertex shaders (minimapa do
  Twilight Princess HD) e escreve todas as entradas do pixel shader (Cars 3, Ninja Gaiden 3, Disney Infinity 3.0)
  (`a95f1b41`, `eca58396`).

#### Drivers do sistema da Adreno e da Mali

- **Sem logic op nos drivers que não têm o recurso `logicOp`:** raster ops diferentes de COPY ligavam o recurso mesmo
  sem o driver ter (inválido no Vulkan, resultado a critério do driver); agora desenham como COPY nesses drivers. Turnip
  e PanVK não mudam (`a0b305c5`).

#### PanVK

- Todo jogo fechava no primeiro quadro com o PanVK do faux123: ele anuncia `VK_KHR_present_wait`, que o sistema de
  janelas do Mesa para Android não implementa. Agora fica desligado no PanVK (`45be70a4`).
- Mais rápido com a mudança de autodependência abaixo (Need for Speed: Most Wanted U, Resident Evil Revelations, FIFA
  13, Bayonetta 2 26,6 → 28,1 fps) e com as cópias de streamout adiadas (`4edbc727`, `451ecf49`).

#### Todos os drivers

- **Draws que amostram o próprio anexo de cor** leem uma cópia feita antes do draw, também onde existe
  `VK_EXT_attachment_feedback_loop_layout` (pontos do Paper Mario) (`70eb6796`); pixel shaders que fazem isso mais de 8
  vezes num quadro voltam ao feedback loop, e o Breath of the Wild mantém a velocidade. `selfdep_copy_max_per_frame`
  (padrão 8) (`4edbc727`). Nos drivers do sistema da Mali e da Qualcomm, que não têm feedback loop, esses shaders dividem
  o render pass em vez de copiar: POCO X6 Pro (Mali) Need for Speed: Most Wanted U 17,2 → 28,8 fps, Resident Evil
  Revelations 24,9 → 30,0 fps, Breath of the Wild 5,9 → 15,6 fps (abertura) (`b96b5dca`).
- **Occlusion queries:** os resultados chegam ao jogo enquanto a GPU está ociosa (`idle_query_poll=0` desliga), queries
  que terminam sem nenhuma query do host rodando concluem, e uma query encerrada duas vezes ou reiniciada cedo é
  tratada (`1557a268`, `e5dc06a1`).
- Um swap sem nada copiado para a tela mantém a última imagem (`de5d2869`).
- Cópias para superfícies 1D usam destinos 2D, como os cubemaps (`dd40e27e`).
- Quando o cache de buffers continua cheio, faixas de streamout sem uso há 2 quadros são descartadas como último
  recurso, e a alocação só é refeita depois de uma falha (`146fdb6e`, `eca58396`).

### Núcleo da emulação

- Herança de prioridade no `OSMutex`, como no Cafe OS (`mutex_inherit=0` desliga) (`5568a685`); `OSGetMapVirtAddrRange`
  e `OSGetDataPhysAddrRange` (`ad5d1dc1`); truncar arquivos no Android, que era um stub também no upstream
  (`8daaafec`); erros do `getsockname` (`6b27c9ae`); reabrir e sair do título no Android (`e2030e99`).
- Um título abre sem uma atualização que sabidamente impede o jogo de carregar (ZombiU v32) (`b6cf7c8b`).
- Os title fixes viraram uma tabela de padrões exatos de código por Title ID (Ninja Gaiden 3, Monster Hunter 3
  Ultimate, New Super Mario Bros. U, Hot Wheels) (`dd4aa043`, `ff719783`, `dfde2b64`).
- Fetch shaders cuja cláusula tem 5-8 ou 13-16 fetches são detectados; erros de pasta ao abrir vão para o log em vez de
  fechar o app (`42a2fbd7`).

### Mudanças

- **A geração de quadros pede a maior taxa de atualização da tela** enquanto está ligada. Celulares que deixam os apps
  em 60 Hz (Moto Edge 30 Ultra, issue #9) cortavam pela metade o fps do próprio jogo, porque os quadros gerados esperam
  a tela (`0f0cc53b`).
- **App menor:** os símbolos de bibliotecas de terceiros não são mais exportados da biblioteca nativa (22,73 → 18,45 MB,
  7,85 MB compactada); recursos sem uso saem no build (recursos 1,49 → 0,83 MB); só as bibliotecas arm64 vão no APK; os
  graphic packs são baixados com o cliente HTTP do próprio Android em vez do Ktor (classes.dex 6,10 → 5,07 MB)
  (`bc69967a`, `10bd5abd`, `5e0236a6`).
- Os botões dos diálogos têm o visual dos botões do app e dividem a largura do diálogo, cancelar à esquerda e confirmar
  à direita, ou se empilham quando um texto não cabe (`af271be2`).
- O overlay clássico mudou de nome e aponta para o HUD de desempenho (`378222ec`).
- Os relatórios de crash dizem qual textura causou o erro quando o cache de texturas para (`dd40e27e`).

### Removido

O Fractal agora é **só Android**: 572 arquivos, cerca de 103 mil linhas. Nada disso fazia parte do app Android, então
nada do que você usa some. Para um emulador de Wii U no PC, use o [Cemu](https://github.com/cemu-project/Cemu).

- A interface de desktop em wxWidgets (janela principal, configurações, depurador, gerenciador de títulos)

### Problemas conhecidos

- **Splinter Cell: Blacklist:** nas missões só o céu e o chão são desenhados (a wiki de compatibilidade do Cemu lista o
  mesmo problema).
- **Assassin's Creed III na Mali:** o terreno próximo pode sair azul-escuro liso (em multi-core o jogo não envia o draw
  do terreno; em single-core ele aparece).
- **The Binding of Isaac: Rebirth (USA):** imagem preta (o som toca, sem crash).
- **FIFA 13:** pode fechar na thread de áudio no RP5 (cerca de 3 runs em 10), com qualquer driver. O campo e o estádio
  ficam pretos em todas as GPUs; o Cemu oficial também mostra tela preta (cemu-project/Cemu#1907).
- **Mario Kart 8 no Mi A3 (Adreno 610):** o jogo fecha ao carregar a corrida (falha de GPU dentro do driver da Qualcomm;
  o Turnip T19 reinicia o celular). Não é mais falta de memória, e o RP5 roda normal.
- **Need for Speed: Most Wanted U:** um crash raro no POCO (não apareceu nas últimas 7 runs); folhagem branca sem o
  pack Bloom Fix (que já vem ligado).
- **Assassin's Creed IV:** a selva ainda pode ficar preta, só com o HUD (raro).
- **Watch Dogs:** a primeira sala pode sair superexposta (clara em vez de escura) em cerca de metade das partidas no
  Android; no RP5 o Turnip pode travar a GPU em sessões longas (use o driver do sistema nele); no Odin 3 o driver do
  sistema às vezes fecha o jogo ao abrir (use o Turnip nele); fica preso compilando shaders no RG Cube.
- **Ninja Gaiden 3 no Turnip:** cabeças escuras flutuando e céu estourado em algumas cenas.
- **Xenoblade Chronicles X no driver do sistema da Qualcomm:** silhuetas brancas; use o Turnip.
- **Pokkén Tournament no Odin 3 (Adreno 830) com o driver do sistema da Qualcomm:** a arena vira ruído colorido nas
  lutas (menus e diálogos ficam normais). Não é novo (a v0.1 também faz); use o Turnip, que desenha certo a 60 fps.
- **Caches de pipelines de outro celular:** o Watch Dogs no Odin 3 fechava ao abrir com um cache feito em outro aparelho
  (os compiladores do Turnip Gen8 e da Qualcomm quebram em algumas das pipelines dele); com o próprio cache ele roda.
- **Celulares com só dois núcleos grandes:** a CPU emulada e a thread da GPU dividem esses dois núcleos. Se um celular
  assim ficou mais lento, `big_cores=0` no `perf/tuning.txt` volta ao comportamento antigo.
- **Texturas nos drivers do sistema da Qualcomm e da Mali** agora são ASTC; se alguma parecer errada, compare com
  `bc_transcode=0` e avise.
- Os drivers customizados para Mali (PanVK) ainda são experimentais. O Android não tem modo de apresentação imediato:
  VSync desligado funciona como buffer duplo.

### Como reportar bugs

Depois de um crash, o Fractal oferece o relatório de depuração na próxima abertura. Você também pode abrir **Opções ›
Compartilhar relatório de depuração** a qualquer hora. Anexe o `debug_report.zip` numa
[nova issue](https://github.com/dfdx047/Fractal/issues/new/choose), com o aparelho, o driver de GPU e o Title ID do
jogo. Pode escrever em português. Não reporte bugs do Fractal para a equipe do Cemu.

Lista completa com o commit de cada correção: [roadmap](https://github.com/dfdx047/Fractal/blob/main/docs/ROADMAP.pt-BR.md) ·
[changelog](https://github.com/dfdx047/Fractal/blob/main/CHANGELOG.md) (em inglês).

## Español

# Fractal v0.2-beta

La segunda beta pública de **Fractal**, un emulador de Wii U para portátiles y teléfonos Android, derivado de Cemu y
ajustado para GPUs Adreno y Mali. Esta versión reúne todo lo que entró desde la build actualizada de la v0.1-beta, del
15 de noviembre de 2026: 118 commits, 814 archivos modificados, unas 30 mil líneas añadidas y 104 mil quitadas (casi
todo código de escritorio).

> **Esto es una beta.** El resultado todavía cambia de un dispositivo o driver de GPU a otro. Haz copias de tus partidas
> y cuéntanos lo que encuentres.

Dispositivos mencionados: **RP5** = Retroid Pocket 5 (Snapdragon 865, Adreno 650), **POCO** = POCO X6 Pro (Dimensity
8300 Ultra, Mali-G615), **Mi A3** = Xiaomi Mi A3 (Snapdragon 665, Adreno 610), **Odin 3** = AYN Odin 3 (Snapdragon 8
Elite, Adreno 830). El **driver del sistema** es el driver Vulkan del propio teléfono (Qualcomm o Arm); **Turnip**
(Adreno) y **PanVK** (Mali) son los drivers personalizados de Mesa.

### Destacados

- **HUD de rendimiento** con el aspecto de tu tema: FPS, tiempo de cuadro, uso de CPU y GPU, temperaturas, RAM, batería
  y consumo. Elige qué muestra, su tamaño, opacidad y disposición, y arrástralo a donde quieras.
- **Graphic packs y trucos en el menú del juego**, aplicados con el juego en marcha (los paquetes de resolución todavía
  piden reiniciar). Los ajustes del juego también se abren desde el menú del juego, con un botón **Reiniciar el juego**.
- **Cachés de shaders de la comunidad:** descarga la caché compartida de un juego desde sus ajustes y juega con menos
  tirones desde la primera vez; comparte la tuya de forma anónima, sin cuenta.
- **Elige dónde guarda Fractal sus datos** (almacenamiento interno o tarjeta SD) e instala mods desde un .zip o una
  carpeta.
- **Las GPUs Samsung Xclipse (Exynos)** ya pueden usar drivers RADV personalizados (aún sin probar en un dispositivo
  Exynos), y el PanVK de faux123 se suma a los drivers para Mali.
- **Más rápido en ARM:** AES y CRC32 por hardware y código NEON nuevo para la lectura de discos, la carga de juegos, los
  index buffers y la decodificación de texturas en Mali; el recompilador trata muchas más instrucciones; la biblioteca
  nativa se compila con optimización guiada por perfil (Watch Dogs en el Odin 3: 51,4 → 56,1 fps); la CPU emulada y el
  hilo de la GPU se quedan en los núcleos grandes (The Amazing Spider-Man 2 en la RP5: 34,9 → 40,3 fps).
- **Menos memoria de texturas con los drivers de Qualcomm y Mali:** las texturas comprimidas siguen comprimidas (en
  ASTC) en lugar de crecer de 4 a 8 veces; Super Mario 3D World usa la mitad de memoria de texturas en un Mi A3.
- **Menos RAM:** las limpiezas de memoria del juego saltan páginas que ya están a cero, y Android no tiene que
  reservarles RAM real (Mario Kart 8 en un Mi A3: 1410 → 997 MB a los 100 s).
- **Juegos con streamout mucho más rápidos en Mali:** Call of Duty: Black Ops II en un POCO X6 Pro pasa de 17 a 35 fps
  con el driver de Mali (3 → 16 con PanVK).
- **Las cachés de shaders ya no se dañan:** un bug heredado de Cemu podía dañar el archivo de caché al crecer, y el
  juego pasaba a usar 2 GB de RAM al arrancar (Android lo cerraba en teléfonos de 4 GB) y a recompilar casi todos los
  shaders. Las cachés dañadas se reparan solas.
- **Solo Android:** se quitó todo el código de escritorio (unas 103 mil líneas) y la biblioteca nativa bajó de 22,7 a
  18,4 MB.
- **Correcciones para Mali:** personajes que faltaban, manchas negras en los normal maps y un cierre por render target
  corregidos con el driver de Mali; PanVK ya no cierra todos los juegos en su primer cuadro.
- **Unos 30 juegos corregidos o mejorados**, de Super Smash Bros. y Splinter Cell: Blacklist a Monster Hunter 3
  Ultimate y Batman: Arkham City, y perfiles por defecto nuevos que eligen el driver que no se cuelga.
- Tipo de control por juego, con un aviso cuando el juego ignora tu configuración; una resolución menor ofrecida una
  vez cuando un juego va muy por debajo de la velocidad completa; música y sonidos del menú elegidos por ti; el informe
  de depuración ofrecido tras un cierre.

  recibe los toques sobre sí mismo.

  está apagado.
- **Uso de GPU en los teléfonos que lo ocultan** (el Mi A3 mostraba N/A): se mide con las marcas de tiempo de los command

  overlay clásico, también son elementos del HUD (desactivados por defecto), y se recogen aunque el overlay clásico
  esté apagado (`378222ec`).

#### Menú del juego

- **Graphic packs y trucos:** una entrada nueva muestra solo los paquetes, trucos y mods del juego en marcha. Activar o
  desactivar un paquete o cambiar un ajuste predefinido lo aplica al juego en marcha, como la ventana de graphic packs
  de Cemu en PC. Los paquetes con reglas de texturas (la mayoría de los de resolución) todavía piden reiniciar, y un
  mensaje dice cuál de los dos casos ocurrió (issue #5) (`c6522627`).
- **Ajustes del juego:** el perfil del juego en marcha se abre con el juego en pausa; los cambios se guardan al momento

#### Cachés de shaders de la comunidad

- Una sección **Shaders de la comunidad** en los ajustes de cada juego descarga la caché compartida de
  [Fractal_Shaders](https://github.com/dfdx047/Fractal_Shaders). Se comprueban su tamaño y su versión, se hace una copia
  de tu caché local y las entradas nuevas se suman a ella (no se reemplaza nada; sin caché local, se copia el archivo).
  Las cachés de Cemu para PC del mismo juego usan el mismo formato (`63968db1`).
- **Compartir es anónimo:** sin cuenta de GitHub; cada instalación envía solo un id aleatorio. Cada envío se revisa antes

- Probado con Deus Ex: compartida desde el POCO y descargada en la RP5, que luego compiló los 92 shaders grandes en la
  pantalla de carga en vez de durante el juego.

#### Carpeta de datos y mods

- **Configuración › Sistema › Carpeta de datos del emulador:** elige una carpeta en el almacenamiento interno o en una
  tarjeta SD en lugar de `Android/data`, que las versiones nuevas de Android ocultan a los administradores de archivos y
  que se borra junto con la app. Fractal pide "Acceso a todos los archivos", mueve los datos (con progreso cuando tiene
  que copiarlos) y se reinicia. Si la carpeta deja de servir (tarjeta retirada, permiso revocado), se vuelve a usar la
  carpeta por defecto y la pantalla lo indica. Al volver a la carpeta por defecto puedes traer los datos o dejarlos
  donde están (`5f607b21`, `af271be2`).
- **Instalación de mods** desde un .zip o una carpeta, en una tarjeta Mods nueva de la pantalla de graphic packs, con

  `content`/`aoc`/`code` de SDCafiine) preguntan el juego y reciben un `rules.txt`, agrupados con los paquetes de ese
  juego (`5f607b21`).

#### Texturas en drivers sin BCn (drivers del sistema de Qualcomm y Mali)

- **BC1-BC3 como ASTC 4x4 (activado por defecto):** en lugar de decodificarlas a RGBA8 (4 veces más grandes en BC2/BC3,
  8 veces en BC1), Fractal las convierte en la CPU a bloques ASTC 4x4 del mismo tamaño que BC, bloque a bloque. Calidad
  frente al original: BC1 53-58 dB, BC3 48,5 dB. Se usa donde los dos formatos ASTC 4x4 se pueden muestrear con filtro
  lineal; las texturas 1D y 3D siguen en RGBA8. Regresión en RP5, POCO, Mi A3 y Odin 3 con todos los drivers, sin
  cierres. `bc_transcode=0` lo desactiva (`5a3ce661`, `07a486b3`, `51de9091`, `e7ca709f`).
- **Decodificación BCn por paleta de cada bloque, con NEON:** un bloque 4x4 tiene como máximo 8 valores, así que la
  paleta se convierte a bytes una sola vez y los texels se copian con búsquedas en tabla NEON, idéntico bit a bit al
  código anterior (`c4e6b0aa`).
- **Ya no se rellena con ceros el búfer de subida:** la imagen decodificada entera se ponía a cero antes de cada capa de
  textura (5,6 MB en una cadena de mips 1024x1024 RGBA8); ahora el búfer solo crece (`cdb338ed`).
- En la build pero **desactivados por defecto:** conversión de BC a ETC2/EAC (`bc_transcode_etc` 1-3; con ASTC
  activado, BC1-BC3 van a ASTC y ETC2/EAC se queda con BC4/BC5; BC1-BC3 en ETC2 costaron un 25 % en Batman en Mali, y
  EAC no dio mejora de fps ni de memoria en el Mi A3), y un grupo de hilos que decodifica texturas grandes por rangos de
  filas (`tex_decode_threads`; decodificación 2,5-2,6 veces más rápida en una prueba en PC, mismos fps en todos los
  teléfonos) (`dc9c0067`, `9c63694e`, `81fcd9a7`).

#### Streamout

- **Las copias de streamout esperan al final del render pass:** los juegos que usan streamout (transform feedback) ya no
  terminan el render pass en cada draw que lo escribe. Mira Black Ops II en la tabla. Regresión en RP5, POCO, Mi A3 y
  Odin 3 sin cierres. `so_defer_copies=0` vuelve al comportamiento anterior (`451ecf49`).

#### CPU y sistema

- **Núcleos grandes:** los núcleos emulados y el hilo de comandos de la GPU se mantienen fuera del clúster pequeño (CPUs
  por debajo del 75 % de la mayor capacidad); Android los ponía en los Cortex-A55 del Snapdragon 865 con la frecuencia
  suficiente para costar mucho. Sin cambios en el POCO y el Mi A3; no se fija nada en CPUs sin clúster pequeño
  (Snapdragon 8 Elite). `big_cores=0` lo desactiva (`683c6772`).
- **Ahorrar batería** (ajustes generales, desactivado por defecto): el núcleo principal emulado ya no gira al 100 % de
  un núcleo del aparato mientras espera trabajo. Si estuvo inactivo al menos el 80 % de los últimos 250 ms, duerme hasta
  la siguiente alarma; un juego que necesita el núcleo sigue girando. Splatoon en el Odin 3 (60 fps): 6,7 → 4,8 W, CPU
  144 → 120 %; New Super Mario Bros. U en el RP5: CPU 147 → 131 %. El coste es un ritmo de fotogramas algo menos
  regular, 2-3 fps de 1 % low (Splatoon 57 → 54, NSMBU 49 → 47). Super Mario 3D World en el RP5, el POCO y el Mi A3 sin
  cambios (`2b5b0dca`, `fb53ac0b`).
- **Optimización guiada por perfil (PGO):** la biblioteca nativa se compila con un perfil recogido en el Odin 3, el POCO
  y el Mi A3 (19 juegos). Watch Dogs en el Odin 3: 51,4 → 56,1 fps (1 % low 41 → 45); Bayonetta 2 y Assassin's Creed
  III en el POCO, un poco más rápidos; RP5 y Mi A3 sin cambios (`0893c8b5`).
- **Sugerencias de rendimiento de Android (ADPF), desactivadas por defecto:** una sesión que informa el trabajo de cada
  cuadro al gobernador de la CPU. Ahorró un 7 % de energía en Watch Dogs en el Odin 3, pero costó fps en el POCO
  (Bayonetta 2 33,2 → 26,3) y 1 % lows en el Odin 3. `adpf=1` las activa (`0893c8b5`).
- **Extensiones ARMv8**, detectadas en tiempo de ejecución para que la build siga funcionando en todo teléfono arm64-v8a
  (AES, PMULL, CRC32, atómicos LSE, FP16, producto escalar): AES-128 en las lecturas de disco cifradas (WUD/WUX,
  contenido NUS), CRC32 en las comprobaciones de cada sección RPX/RPL al cargar, y un máximo de index buffer con NEON que
  salta el índice de primitive restart (`b1078675`, `852801bb`, `64efc3e5`, `bd6af3dc`).

#### Recompilador (PowerPC → ARM64)

- `addo`/`subfo`/`addco`/`subfco`, `mfxer`/`mtxer`, `fcmpo`, saltos al estilo `bdnzf`, saltos condicionales fuera del
  código traducido, `subfme`, `divwo`/`divwuo` y `bcl 20` ya no mandan funciones al intérprete (`66f59e89`,
  `85b29bd9`).
- Una función contigua enorme se traduce por ventanas en lugar de entera en cada entrada nueva: en Teslagrad un switch
  de 955 KB se traducía 22 veces (92 MB de código host). Teslagrad en el Mi A3: funciones en el intérprete
  770 → 157 → 0; Disney Infinity 2.0: 145 → 0. Regresión: 17 juegos en RP5, POCO y Mi A3 con los mismos fps e imagen
  (`66f59e89`, `85b29bd9`).
- La multiplicación-suma fusionada (`fmadd`/`fmsub`/`fnmsub` y sus formas single) redondea una sola vez, como la CPU de
  Wii U y el intérprete; antes, `a*c - round(a*c)` daba cero solo en el código recompilado. Misma velocidad e imagen en
  Ninja Gaiden 3, Spider-Man 2 y Splinter Cell: Blacklist (`fec3837f`).
- `stwcx.` en una dirección no alineada ya no cierra el juego (se convertía en un atómico de ARM64 que exige alineación
  de 4 bytes) (`70eb6796`).

#### Memoria

- **Caché de búferes de la GPU de 256 MB** en teléfonos con 6 GB de RAM o más (por debajo, los 164 MB de Cemu); mira
  Cars 3. `buffer_cache_mb` cambia el valor (`f3f03341`).
- **Limpiezas de memoria del juego más ligeras (`lazy_zero`, activado por defecto):** las limpiezas de 16 KB o más
  saltan páginas de 4 KB que ya están a cero, y Android no tiene que reservarles RAM real. Mario Kart 8 en el Mi A3: RAM
  del proceso a los 100 s 1410 → 997 MB; Watch Dogs salta 512 MB de limpiezas; mismos fps. `lazy_zero=0` lo desactiva
  (`e4ae9d51`).

Todas las claves de arriba van en `perf/tuning.txt`, en la carpeta de datos de Fractal; sin el archivo se usan los
valores por defecto.

### Gráficos y drivers

#### Mali (driver del sistema de Arm)

- **Streamout mediante `VK_EXT_transform_feedback`** donde el driver no permite escrituras en búferes desde el pipeline
  de vértices (el driver de Mali): Yoshi y los enemigos vuelven en Yoshi's Woolly World. `so_xfb` (-1 automático, 1
  siempre, 0 nunca) (`95904874`).
- **Texturas BC4/BC5 SNORM** (normal maps, en cualquier juego) bien decodificadas en la CPU: los valores negativos
  quedaban en 0 y los mayores de 0,5 se volvían negativos (`95904874`).
- **Render targets A2_B10_G10_R10** con un formato Vulkan (Resident Evil Revelations se cerraba; los drivers de Adreno lo
  toleraban) (`71f3a05a`).

#### Adreno (driver del sistema de Qualcomm)

- **Shaders que leen y escriben registros por índice** usan variables separadas en lugar de un array, que tumbaba el
  compilador de Qualcomm (Pikmin 3). `relread_select=0` mantiene la forma con array (`ab851c1a`).
- **Geometry shader de la emulación de rects:** ahora declara el mismo `gl_PerVertex` que los vertex shaders (minimapa
  de Twilight Princess HD) y escribe todas las entradas del pixel shader (Cars 3, Ninja Gaiden 3, Disney Infinity 3.0)
  (`a95f1b41`, `eca58396`).

#### Drivers del sistema de Adreno y Mali

- **Sin logic op en drivers que no tienen la función `logicOp`:** las raster ops distintas de COPY la activaban aunque el
  driver no la tuviera (inválido en Vulkan, resultado a criterio del driver); ahora dibujan como COPY ahí. Turnip y PanVK
  no cambian (`a0b305c5`).

#### PanVK

- Todos los juegos se cerraban en su primer cuadro con el PanVK de faux123: anuncia `VK_KHR_present_wait`, que el
  sistema de ventanas de Mesa para Android no implementa. Ahora está desactivado en PanVK (`45be70a4`).
- Más rápido con el cambio de autodependencia de abajo (Need for Speed: Most Wanted U, Resident Evil Revelations, FIFA
  13, Bayonetta 2 26,6 → 28,1 fps) y con las copias de streamout diferidas (`4edbc727`, `451ecf49`).

#### Todos los drivers

- **Los draws que muestrean su propio adjunto de color** leen una copia hecha antes del draw, también donde existe
  `VK_EXT_attachment_feedback_loop_layout` (los puntos de Paper Mario) (`70eb6796`); los pixel shaders que lo hacen más
  de 8 veces en un cuadro vuelven al feedback loop, y Breath of the Wild conserva su velocidad.
  `selfdep_copy_max_per_frame` (8 por defecto) (`4edbc727`). En los drivers del sistema de Mali y Qualcomm, que no tienen
  feedback loop, esos shaders dividen el render pass en lugar de copiar: POCO X6 Pro (Mali) Need for Speed: Most Wanted U
  17,2 → 28,8 fps, Resident Evil Revelations 24,9 → 30,0 fps, Breath of the Wild 5,9 → 15,6 fps (apertura) (`b96b5dca`).
- **Occlusion queries:** los resultados llegan al juego mientras la GPU está inactiva (`idle_query_poll=0` lo
  desactiva), las queries que terminan sin ninguna query del host en curso se completan, y se maneja una query terminada
  dos veces o reiniciada antes de tiempo (`1557a268`, `e5dc06a1`).
- Un swap sin nada copiado a la pantalla mantiene la última imagen (`de5d2869`).
- Las copias a superficies 1D usan destinos 2D, como los cubemaps (`dd40e27e`).
- Cuando la caché de búferes sigue llena, los rangos de streamout sin usar durante 2 cuadros se descartan como último
  recurso, y la reserva solo se reintenta tras un fallo (`146fdb6e`, `eca58396`).

### Núcleo de la emulación

- Herencia de prioridad en `OSMutex`, como Cafe OS (`mutex_inherit=0` la desactiva) (`5568a685`);
  `OSGetMapVirtAddrRange` y `OSGetDataPhysAddrRange` (`ad5d1dc1`); truncar archivos en Android, que también era un stub
  en upstream (`8daaafec`); errores de `getsockname` (`6b27c9ae`); reiniciar y salir del título en Android
  (`e2030e99`).
- Un título arranca sin una actualización que se sabe que impide cargarlo (ZombiU v32) (`b6cf7c8b`).
- Los title fixes ahora son una tabla de patrones exactos de código por Title ID (Ninja Gaiden 3, Monster Hunter 3
  Ultimate, New Super Mario Bros. U, Hot Wheels) (`dd4aa043`, `ff719783`, `dfde2b64`).
- Se detectan los fetch shaders cuya cláusula tiene 5-8 o 13-16 fetches; los errores de carpetas al iniciar van al log en
  vez de cerrar la app (`42a2fbd7`).

### Cambios

- **La generación de cuadros pide la tasa de refresco más alta de la pantalla** mientras está activada. Los teléfonos que
  dejan las apps a 60 Hz (Moto Edge 30 Ultra, issue #9) reducían a la mitad los fps del propio juego, porque los cuadros
  generados esperan a la pantalla (`0f0cc53b`).
- **App más pequeña:** los símbolos de bibliotecas de terceros ya no se exportan desde la biblioteca nativa
  (22,73 → 18,45 MB, 7,85 MB comprimida); los recursos sin uso se quitan al compilar (recursos 1,49 → 0,83 MB); solo se
  empaquetan bibliotecas arm64; los graphic packs se descargan con el cliente HTTP del propio Android en lugar de Ktor
  (classes.dex 6,10 → 5,07 MB) (`bc69967a`, `10bd5abd`, `5e0236a6`).
- Los botones de los diálogos tienen el aspecto de los botones de la app y se reparten el ancho del diálogo, cancelar a
  la izquierda y confirmar a la derecha, o se apilan cuando un texto no cabe (`af271be2`).
- El overlay clásico cambió de nombre y remite al HUD de rendimiento (`378222ec`).
- Los informes de cierre dicen qué textura causó el error cuando la caché de texturas se detiene (`dd40e27e`).

así que no desaparece nada de lo que usas. Para un emulador de Wii U en PC, usa [Cemu](https://github.com/cemu-project/Cemu).

- La interfaz de escritorio en wxWidgets (ventana principal, ajustes, depurador, gestor de títulos) (`9aa94b36`).
- Los renderizadores OpenGL y Metal; Vulkan era el único que usaba la build de Android (`ee6e63b1`).
- El recompilador x86-64 y la detección de CPU x86 (`d07f65ea`).
- El código de Windows, macOS y Linux de escritorio, instaladores, iconos y paquetes, y la herramienta para unir cachés
  de shaders (`54b44032`).
- SDL, XInput, DirectInput, Wii Remotes nativos y el adaptador de GameCube, DirectSound y XAudio, y Discord Rich
  Presence (`4d4403c3`).
- Opciones de compilación, empaquetado y CI de escritorio (`4b0f2868`).
- Código nativo y Kotlin que nadie llamaba, incluidas las pruebas unitarias antiguas (`56d83cd7`, `054ddf0f`).
- Los ajustes y los perfiles de juego conservan los mismos valores, así que la configuración existente carga como antes.

  `jit_fma`, `jit_max_function_kb`, `selfdep_copy_max_per_frame`, `watch_jit`, `save_battery`, `idle_wait_max_us`,
  `idle_spin_us`, `idle_sleep_min_pct`, `idle_alarm_wake` (`2c2431f1`, `f4d8191f`, `2b5b0dca` y los commits de arriba).
- **Vigilancia de escrituras para código recompilado** (`watch_jit=1`): las escrituras en un rango vigilado van al log
  con el PC del host, el LR del juego y el hilo (`e79e82bd`).
- **Log de rendimiento:** espera de GPU separada para las copias bloqueantes de superficies lineales
  (`gw_linearcopy_ms`); tiempo y tamaño de la decodificación de texturas en `seconds.csv`; el log de relojes añade
  corriente y voltaje de la batería y de la entrada USB y la zona de temperatura de la carcasa, y sobrevive a nodos
  ausentes (se detenía en el Odin 3); `frame_map` lista copias, limpiezas, sincronizaciones de texturas y readbacks;
  eventos para raster ops, strides de vértices fuera de lo normal y el cambio de autodependencia (`52ff15de`,
  `9c63694e`, `0f6a40ba`, `6fa032a8`, `1557a268`, `a95f1b41`, `4edbc727`).
- **Scripts de entrada:** toque en el GamePad (`TOUCH`, `DRAG`) para juegos de stylus, y botones mantenidos durante un
  número de cuadros; el ejecutor de escenas nunca toca la pantalla cuando otra app está al frente, abre juegos por ruta
  (`LAUNCH_PATH`) y encuentra títulos combo por su nombre corto (`6a78d980`, `5568a685`, `e5dc06a1`, `1557a268`).
- **`tools/neon_tests`:** pruebas independientes que comparan cada ruta NEON, los decodificadores de texturas repartidos
  entre hilos y los conversores ASTC y ETC2/EAC con código de referencia, bit a bit o por márgenes de error
  (`852801bb`, `c4e6b0aa`, `9c63694e`, `5a3ce661`, `dc9c0067`).
- **79 escenas de benchmark nuevas** en `tools/perf/scenes`, de Smash, Splatoon y Twilight Princess HD a primeras
  pruebas de unos 50 juegos de la rotación (LEGO, Disney Infinity, Transformers, Pac-Man, Scribblenauts, Angry Birds y
  muchos más). Que haya una escena significa que el juego se ejecutó, no que funcione bien.
- `docs/REGISTRO-MUDANCAS.md`: un registro de los cambios arriesgados, cómo se probó cada uno y cómo desactivarlo, para
  buscar regresiones (en portugués) (`0f6a40ba`).

### Requisitos

- Android 11 o posterior, ARM de 64 bits (arm64-v8a), GPU con Vulkan 1.1.
- Adreno 6xx/7xx y Mali. Los drivers personalizados para Samsung Xclipse aún no se han probado.
- Probado en Retroid Pocket 5 (Snapdragon 865), POCO X6 Pro (Dimensity 8300 Ultra, Mali-G615), Xiaomi Mi A3
  (Snapdragon 665) y AYN Odin 3 (Snapdragon 8 Elite); builds anteriores también en Anbernic RG Cube (Mali-G57), AYN
  Odin 2 Mini y AYN Thor.

### Instalación

Descarga el APK de abajo, instálalo y sigue la configuración inicial. Fractal no incluye ni descarga juegos, claves ni
firmware: usa copias de juegos que tengas. Los juegos descifrados (.wua) no necesitan claves.

### Problemas conocidos

- **Splinter Cell: Blacklist:** en las misiones solo se dibujan el cielo y el suelo (la wiki de compatibilidad de Cemu
  lista el mismo problema).
- **Assassin's Creed III en Mali:** el terreno cercano puede salir azul oscuro liso (en multi-core el juego no envía el
  draw del terreno; en single-core sí aparece).
- **The Binding of Isaac: Rebirth (USA):** imagen negra (el sonido funciona, sin cierres).
- **FIFA 13:** puede cerrarse en su hilo de audio en la RP5 (unas 3 de cada 10 pruebas), con cualquier driver. El campo
  y el estadio salen negros en todas las GPUs; el Cemu oficial también muestra pantalla negra (cemu-project/Cemu#1907).
- **Mario Kart 8 en el Mi A3 (Adreno 610):** el juego se cierra al cargar la carrera (un fallo de GPU dentro del driver
  de Qualcomm; con Turnip T19 el teléfono se reinicia). Ya no es falta de memoria, y el RP5 lo ejecuta normal.
- **Need for Speed: Most Wanted U:** un cierre poco frecuente en el POCO (no apareció en las últimas 7 pruebas); follaje
  blanco sin el paquete Bloom Fix (activado por defecto).
- **Assassin's Creed IV:** la selva todavía puede quedar negra, solo con el HUD (raro).
- **Watch Dogs:** la primera sala puede verse sobreexpuesta (clara en lugar de oscura) en cerca de la mitad de las
  partidas en Android; en el RP5 Turnip puede colgar la GPU en sesiones largas (usa ahí el driver del sistema); en el
  Odin 3 el driver del sistema a veces lo cierra al abrir (usa ahí Turnip); se queda compilando shaders en la RG Cube.
- **Ninja Gaiden 3 en Turnip:** cabezas oscuras flotando y cielo quemado en algunas escenas.
- **Xenoblade Chronicles X con el driver del sistema de Qualcomm:** siluetas blancas; usa Turnip.
- **Pokkén Tournament en el Odin 3 (Adreno 830) con el driver del sistema de Qualcomm:** la arena se convierte en ruido
  de colores en los combates (menús y diálogos se ven bien). No es nuevo (la v0.1 también lo hace); usa Turnip, que lo
  dibuja bien a 60 fps.
- **Cachés de pipelines de otro teléfono:** Watch Dogs en el Odin 3 se cerraba al arrancar con una caché hecha en otro
  dispositivo (los compiladores de Turnip Gen8 y de Qualcomm fallan con algunas de sus pipelines); con su propia caché
  funciona.
- **Teléfonos con solo dos núcleos grandes:** la CPU emulada y el hilo de la GPU comparten esos dos núcleos. Si un
  teléfono así va más lento, `big_cores=0` en `perf/tuning.txt` vuelve al comportamiento anterior.
- **Las texturas con los drivers del sistema de Qualcomm y Mali** ahora son ASTC; si alguna se ve mal, compárala con
  `bc_transcode=0` y avísanos.
- Los drivers personalizados para Mali (PanVK) todavía son experimentales. Android no tiene modo de presentación
  inmediata: VSync desactivado funciona como doble búfer.

### Cómo reportar errores

Tras un cierre, Fractal ofrece el informe de depuración en el siguiente inicio. También puedes abrir **Opciones ›
Compartir informe de depuración** cuando quieras. Adjunta `debug_report.zip` a un
[nuevo issue](https://github.com/dfdx047/Fractal/issues/new/choose), con el dispositivo, el driver de GPU y el Title ID
del juego. Puedes escribir en español. No reportes errores de Fractal al equipo de Cemu.

Lista completa con el commit de cada corrección: [roadmap](https://github.com/dfdx047/Fractal/blob/main/docs/ROADMAP.es.md) ·
[changelog](https://github.com/dfdx047/Fractal/blob/main/CHANGELOG.md) (en inglés).
